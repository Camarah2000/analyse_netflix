# Analyse Netflix

## Description

Le but de ce projet est de mettre en pratique les connaissances que j'ai acquises en **Pandas** lors de ma formation sur Udemy.

Dans ce projet, j'ai travaillé sur un jeu de données contenant des informations sur les films et séries Netflix.

## Travail réalisé

- Data cleaning (nettoyage et préparation des données)
- Vérification des valeurs nulles et des doublons
- Modification des types de données
- Manipulation et transformation des DataFrames
- Data modeling (modélisation des données)

## Technologies utilisées

- Python
- Pandas
- Jupyter Notebook
- GitHub
